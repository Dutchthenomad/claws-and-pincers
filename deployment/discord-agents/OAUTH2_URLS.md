## Troubleshooting:

**Bot doesn't appear offline:**
- Check that containers are running: `docker ps | grep openclaw`
- Check logs: `docker logs openclaw-orchestrator`

**Bot doesn't respond to mentions:**
- Verify bot has permission to read messages in the channel
- Check that the bot is online (green dot)
- Try @ mentioning with exact username

**Can't invite bot:**
- You need "Manage Server" permission in the Discord server
- Or have the server owner invite them
